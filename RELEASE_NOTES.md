## OfflinePay Wallet 2.0

**Works on its own — no laptop or server needed.** Install the APK, pick PayA or PayB, create an account and go.

### What's new
- Familiar wallet layout: green header, balance card with hide/show, quick actions, services grid, and a bottom bar with a raised **Scan** button.
- Offline Pay built in: the app tells you when you're offline and that you can still pay from your Offline Vault.
- 3-step intro that explains Offline Pay the first time.
- The whole backend (accounts, wallet, settlement and fraud checks) runs on the phone.
- New app icon and green status bar.
- Fixed signing key, so future versions install as updates.

### Install
1. Download **OfflinePay-Wallet.apk** below and open it on an Android phone.
2. Allow installing from this source if Android asks.
3. **If you installed an earlier build (1.x), uninstall it first** — it was signed with a different key.

### Two-phone demo
- Phone 1: **PayA**, personal account, open Offline Pay, then load the vault.
- Phone 2: **PayB**, merchant account, set up Offline Pay.
- Turn on airplane mode on both. The merchant taps **Receive**, the customer taps **Scan**, and the merchant scans the customer's code.
- Turn the internet back on and the payment settles. Try the attack tools to show fraud being caught.
